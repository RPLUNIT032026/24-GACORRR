# 🧮 Perhitungan Function Point — DTG

**Function Point (FP)** adalah cara mengukur besar aplikasi dari fiturnya. Setiap fitur diberi skor, lalu dijumlahkan.

---

## 📋 Fitur & Skor

| Fitur | Jenis | Skor |
|---|---|---|
| Kirim data sensor | Input data | 4 |
| Kelola zona gudang | Input data | 3 |
| Login admin | Input data | 3 |
| Grafik riwayat | Tampilan hasil | 5 |
| Alarm bahaya | Tampilan hasil | 5 |
| Lihat status zona | Lihat data | 3 |
| Data zona | Penyimpanan | 7 |
| Data sensor | Penyimpanan | 10 |
| Data alarm | Penyimpanan | 7 |
| Data pengguna | Penyimpanan | 7 |
| **TOTAL** | | **54** |

---

## ⚙️ Penyesuaian

Setelah kami menilai kondisi proyek, faktor penyesuaiannya **1,02**.

---

## ✅ Hasil Akhir

```
Function Point = 54 × 1,02 ≈ 55 FP
```

**Kesimpulan:** DTG berukuran sekitar **55 Function Point**.
